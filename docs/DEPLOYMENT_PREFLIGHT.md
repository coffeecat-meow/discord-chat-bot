# 測試部署前準備與真實平台驗收

2026-10-15。本頁落實 [R02–R04](RELEASE_READINESS.md) 的準備工作；表中的平台狀態目前都是「待實測」，不是已部署或已通過。

## 不必先提供 SSH 的環境盤點

已在 `scripts/check_installation.py` 增加 `--host-only`。這個模式只用 Python 標準庫，不需要先安裝 Bot 或提供 `.env`；不查服務密鑰、不改配置、不開資料庫、不發網路請求，也不啟停服務。

在目標伺服器有腳本副本後，可執行：

```sh
python3 /path/to/check_installation.py --host-only
```

輸出 OS／Linux 發行版、CPU 架構、Python、是否在 venv、uv／Obscura 的 PATH 位置。它不猜測目前 4.0 的服務名稱，也不把本機 macOS 結果當 Debian 證據。

若不方便傳腳本，先提供下面兩項輸出也能開始核對：

```sh
python3 --version
cat /etc/os-release
```

CPU 架構可另用 `uname -m`。現有服務的名稱、工作目錄與啟動方式仍需確認；不要貼環境變數、`.env`、Bot token、key 或可能內含憑證的完整啟動命令。

安裝完成後再依 [INSTALLATION](INSTALLATION.md) 執行依賴檢查、數學預熱及指定部署配置的 `--check`。`--host-only` 不檢查網路、Discord 權限或外部 binary 實際可執行性。

## 執行順序

1. 只讀確認主機及準備獨立環境，不動 4.0。
2. 選定測試身分／頻道與模型配置，使用新測試資料庫即可先跑平台驗收。
3. 先驗 D01–D08，再按預定可測動作驗 D09–D14；不具備權限的項目列未驗，不假定通過。
4. R06 觀測真實多人聊天，分開記排隊／模型／工具／人工等待，以及每回合 token／呼叫數。
5. 真資料遷移與正式服務啟停仍依 [R05／R07 決策](RELEASE_READINESS.md)，不因拿到 SSH 或 Bot token 就自行切換。

目前仍缺真實主機資訊、測試 Bot／guild／channel 及可測範圍；這些資料未提供前，表格保持待實測。既有離線與合成模型成果不因此失效，也不重做成另一套 Bot。
