# 4.6 RC 連續製作與驗收

更新至2026-10-17。使用者已確認七項建議，並指定模擬環境驗收完成即可達成本目標。此為單一主交付，隨工作更新；目前狀態：**4.6.0rc1 已完成約定的模擬驗收與套件交付；未部署，未宣稱真實平台正式版完成**。

## 已核准的範圍

- RC／模擬驗收為終點，無須連 Discord／SSH／部署；未實測的平台範圍照實交付。
- 工程、來源、權限、動作契約必修；純聊天時間／重述等可保留已知限制，不無限研究。
- 背景摘要／自動畫像納入，驗證後啟用；使用新庫，舊資料不改不搬。
- 原文與長期記憶不自動按短 TTL 清除；普通診斷30天；清除後舊檔不得靜默復活，明確恢復才可匯入。
- 按預定驗收通過的最小修復可自行接入。人設及既有睡眠、按鈕、共享政策不改。
- 預設 Go DS V4.1，呼叫失敗改用 OpenRouter並記錄 log。大小模型與視覺模型各有自己的模型／主備endpoint／key名稱，順序完全由配置決定；不重播已完成工具。
- 本目標允許必要的 Go API；**OpenRouter 只做模擬，所有真實測試禁止 OR 出站**。
